# 代码维护

网站保持原生 HTML/CSS/JavaScript，无运行时框架与第三方依赖。ES 模块直接由浏览器加载。

- `app.js`：编辑器控件、历史记录及初始化。
- `src/config.js` / `src/model.js`：默认搭配、坐标、Rating 分档与模板校验。
- `src/assets.js`：清单读取、分组归一化、请求去重与图片内存缓存。
- `src/renderer.js`：独立画布合成；异步加载期间使用状态快照，旧请求不能覆盖新画面。
- `src/picker.js`：分类、搜索、分页及素材记忆定位。
- `src/templates.js`：本地模板、JSON 导入导出及存储错误处理。
- `author-recommendations.js`：公开搭配与本地作者管理，通过显式参数连接编辑器。
- `sw.js`：有效图片长期缓存、清单网络优先、离线回退。
- `styles.css`：界面布局；`ui-motion.*`：交互反馈；`BG`：背景资源与适配。

## 检查与预览

- `npm ci`：安装开发检查工具。
- `npm run dev`：在 127.0.0.1:4173 预览。
- `npm run check`：静态检查、单元测试与发布目录生成。
- `npm run test:e2e`：运行浏览器回归，使用 4174 端口的 dist；本机使用 Chrome，CI 使用 Playwright Chromium。
- `npm run build`：生成 dist，仅包含公开运行文件，不包含测试、工具、原始取样或备用背景。背景归档仍保留在 Git 仓库中。

GitHub Pages 在检查通过后只上传 dist。不要将未确认的本地素材或调试输出一并加入提交。

发布目录会按脚本与样式内容生成缓存版本参数，并同步到模块导入，避免旧模块与新入口混用。素材仍沿用原来的长期缓存，不因代码更新全部重下载。

PowerShell 素材维护脚本保留为手动工具；`sync-lxns-2026-assets.ps1` 需要维护者准备对应的本地 LXNS 元数据 JSON。检查流程只验证脚本语法，不会自动同步或覆盖素材数据。

## 需保留的约束

默认 Rating 为 16411。导出 2160 × 904 PNG；头像仅允许不超过 720 × 720 的正方形。名称最多八个可见字符。历史最多五步。套用作者推荐只替换外观，保留玩家信息及显示状态。

素材清单只在完整校验后写入缓存；刷新参数不能改变离线缓存键；失败请求必须可重试。浏览器存储被禁用或写满时，不应使普通素材加载失效。模板导入失败不得部分改变当前配置。
