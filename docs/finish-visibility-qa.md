# 细粉与闪粉可见度回归验证

基线为 PR #52 合并后的 `9aa872b`。本次检查范围是 3D 细粉、背景闪粉及其直接相关的材质隔离、视角、取景和导出流程，不代表全站缺陷穷尽检查。

## 原因与修正

- 颗粒倾角使用 `sqrt(seed)` 分布，偏向大倾角。亚克力折射把观察/入射方向压向印刷面法线，默认视角能接到高光的颗粒过少。改为保留大倾角尾部、同时增加浅倾角颗粒的稳定分布，且只在颗粒内增加有界反射。
- 颗粒 LOD 的 `dFdx/dFdy` 原本在不同像素可能选择不同路径的遮罩分支内，GLSL 不保证这种导数结果。改为在分支之前计算，并以实际显示像素选择层级。
- 全景使用固定的最小距离，360px 手机布局的图案仅约 110px 宽。改为按产品角点、屏幕比例拟合全景和近景；窗口变化和切换产品时保留观察方向并重新取景。
- 细粉强度为零时以前仍保留漫反射凹凸，现与关闭细粉一致。

## 自动检查

- `npm run check`：lint、95 项单元测试、build。
- 相关 Playwright 测试：桌面/手机特写、近景及全景，材质切换，2D PNG 与两种 JSON 下载，透明玻璃内部捕获，颗粒光照/视角响应与静止稳定。
- 新的生产 shader 可见度测试在深色、浅色、饱和色上渲染亚克力与色纸，并使用细窄遮罩。对显示尺寸的图像比较，要求有足够多的像素变化超过 5/255、峰值超过 15/255，而不再仅断言 PNG 字符串不同。
- 隔离测试覆盖选区、未选区、文字保护、基础款、总开关、强度为零、镭射及色纸。

## 实际素材对比

使用未修改的生产模块、真实素材和运行时生成的遮罩：

- 默认搭配，以及用户提供的鏡舞舞/Amethyst 搭配。
- 360px 触控布局、DPR 3 手机模拟，以及 960px 桌面布局。
- 全景、近景、姓名框特写；分别关闭细粉、闪粉和两者，比较 CSS 尺寸截图。
- 灯位 15°/60°、键盘旋转、重复静止画面；另检查斜后方视角在 360→320px、托架/色纸/亚克力切换后仍正常。

仅修改 shader、保持原取景的中间版本，用用户模板做同视角对比：手机特写中，细粉开关造成超过 15/255 变化的像素由 731 增至 1118，背景闪粉由 1290 增至 5859。最终全景同时改善取景，所以其变化数量不能单独解释为 shader 强度提升。最终默认模板手机全景的细粉对应像素由 32 增至 218，闪粉由 74 增至 1560。

以上是像素可见度指标，不是实物颗粒尺寸、反射率或用户视觉体验的标定。比对不采用后期补光、锐化或叠加颗粒。差分图若放大差异会单独标注。

## 验证限制

运行环境为桌面 Chromium 的 SwiftShader 软件 WebGL。手机为尺寸、DPR 与触控模拟，未在实体 iPhone/Android GPU 或 Safari 上验证。GPU 自动分级在该软件环境选择 balanced，另有高分屏上下文的生产回归；不能据此声称所有实体 GPU 均通过。页面交互/下载自动测试使用隔离的图像夹具，真实素材的外观结论来自上述独立生产渲染矩阵。

此次提交不恢复用户界面的 3D PNG 导出，不合并或部署；原有平面 PNG、模板 JSON 和定制方案 JSON 保留。
