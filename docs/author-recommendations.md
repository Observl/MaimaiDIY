# 本地管理作者推荐

1. 打开本地模拟器，搭配好背景板、姓名框、头像与称号。
2. 在“组件”最下方点击“作者推荐”。
3. 填写推荐名称，点击“添加当前搭配”。推荐包含完整渲染预览；同名保存会覆盖该本地推荐。
4. 可继续制作其他搭配，也可以删除已有本地推荐。
5. 点击“导出推荐配置”备份 recommendations.json。需要公开时，将导出文件保存为项目 materials/recommendations.json，随网站一起发布。

本地保存只存在于当前浏览器。添加、删除和导出按钮仅在 localhost / 127.0.0.1 本地预览显示，公开站点的访客只能预览和套用推荐。当前附带一套作者默认搭配作为示例。

套用仅替换背景、姓名框、头像和称号，保留名称、Rating、段位、友人对战及这些项目的显示开关，支持撤回。
