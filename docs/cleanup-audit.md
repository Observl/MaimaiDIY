# 代码整理与回归记录

范围：编辑器入口、状态与坐标配置、画布合成、素材与清单缓存、选择器分页/搜索/记忆、模板、作者推荐、交互动效、背景适配、打赏入口、维护脚本及 Pages 发布流程。版本保留 v1.2.1。

## 整理内容

- 将大入口中的数据、渲染、素材请求、选择器与模板管理拆成明确的 ES 模块；推荐功能通过参数连接编辑器，不再读取隐式全局状态。
- 统一默认状态与模板校验，复用有效清单请求；只在素材地址变化时更新组件缩略图。
- 移除无用的控件副本、旧样式与无效字体预加载；背景适配不再覆盖编辑器界面样式。
- 旧 support.html 保留为主页面支持区的跳转入口，不再维护第二份打赏页面。
- 删除不再使用的官网整站抓取、重复背景取样和旧调试截图；实际背景、Magical 备用背景、用户推荐配置与当前 README 图片保留。
- 发布目录采用明确的文件范围，并统一生成脚本/样式缓存版本；工具、测试和归档副本不上传 Pages。

## 修复的问题

- 清单刷新参数导致离线缓存键不一致；错误 HTTP 响应、格式错误的清单及损坏图片不能替换有效缓存。
- 旧图片缓存缺少校验标记时进行一次验证；失败缓存淘汰后允许重试。空响应、HTML 假字体不会长期保存。
- 禁用浏览器缓存存储时仍可正常从网络读取素材。
- 导入失败或存储写满时不再部分修改编辑器状态；载入本地模板使用相同校验，拒绝越界/外部素材地址。
- 恢复名称时清除旧的超长输入标记；自定义头像校验类型、比例和尺寸，临时地址始终释放。
- 异步渲染使用快照与请求版本，旧图片完成加载不能覆盖新画面；制作推荐预览时拒绝缺素材的画面。
- 素材选择器防止过期打开请求覆盖当前列表，并容忍损坏的本地选择记录。

## 验证

- `npm run check`：ESLint、15 项单元测试及发布构建。
- `npm run test:e2e`：7 组浏览器测试，覆盖默认值、2160 × 904 导出、大屏、五步历史、清空、名称限制、模板往返及失败原子性、所有素材类型分类、记忆定位、全部五套推荐、手机布局、动效偏好和头像限制。
- Windows Chrome 中，默认高清导出与整理前基准逐像素一致；跨系统 CI 允许字体栅格边缘差异，但非文字部分仍严格比对。
- 回归端口 4174 不在实际 COS 本地白名单内，测试只调整响应的允许来源头，保留真实云端素材内容；正式网站跨域加载另行在线检查。
- 手工检查桌面和 320px 手机页面；PowerShell 维护脚本只做语法检查，未运行数据同步或覆盖本地素材。

GitHub Pages 需通过同一套检查和浏览器回归后才部署。工作区原有的未提交素材、许可证和数据改动不包含在本次整理中。
